# HR Analytics Dashboard

## Project Overview
This project analyzes employee performance, retention, and workforce trends using SQL, Python, and Tableau.

## Tools Used
- SQL
- Python (Pandas, Matplotlib)
- Tableau

## Key Insights
- Employee retention rate
- Attrition analysis
- Department-wise performance
- Salary and satisfaction trends
- Employee demographics

## Dashboard Features
- Total Employees
- Attrition Rate
- Employee Satisfaction Score
- Department Performance
- Salary Distribution
- Retention Analysis

## Files Included
- employee_data.csv
- HR ANALYTICS SQL.sql
- HR ANALYTICS PYTHON.py
- HR ANALYTICS TABLEAU.twb
